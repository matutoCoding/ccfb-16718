# 葡萄架式冠层受光推演系统

浏览器内运行的葡萄园冠层光照与果穗晒伤推演工具。使用 Vue 3 + TypeScript + Vite 构建三维界面，使用手写 WGSL Compute Shader 计算逐叶片直射/散射累计、行间遮挡和果穗午后直射/温度风险，地块与方案保存在浏览器 IndexedDB。

## 启动

需要 Node.js 20.19+ 或 22.12+，推荐 pnpm。

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

纯逻辑测试：

```bash
pnpm test
```

> WebGPU 推演建议使用最新版 Chrome / Edge，并确认 `chrome://gpu` 中 WebGPU/Hardware acceleration 可用。无 WebGPU 时会自动使用 CPU 参考求解器，精度公式不变，但一亩冠层耗时会更高。

## 已实现页面

1. **地块档案**：纬度、经度、时区、坡向、坡度、默认行向、备注；支持 GeoJSON / 坐标数组 / `{x,y}` 边界导入，自动计算面积。
2. **架式设计**：单篱架、V 形架、棚架；行距、株距、架高、铁丝层数、立柱间距、结果带高度、V 形开张度和方案行向；参数变化后三维预览即时重建并自动保存。
3. **冠层生长**：8 个物候期、LAI 目标、单叶面积、新梢/叶片/果穗密度、果穗带摘叶、疏梢比例；程序化掌状叶纹理和确定性随机生成。
4. **受光推演**：NOAA 风格太阳位置、真太阳时、大气质量和晴空 DNI；直射/散射分离；WGSL 中逐叶累计时间序列和日总量；体素 Beer-Lambert 遮挡计算行间/株间阴影；三维热图与时间轴动画。
5. **果穗评估**：逐果穗午后直射分钟、全天直射分钟、暴露率、峰值果温、晒伤阈值和风险标记；三维果穗风险着色，表格可筛选和导出。
6. **方案对比**：同一地块选择 2–4 个架式/行向方案，顺序推演并并排比较平均受光、P10/P50/P90、弱光比例、果穗风险和行级统计。
7. **设置**：WebGPU/CPU 引擎选择、时间步长、体素尺寸、消光系数、温度阈值、体素调试显示、IndexedDB 备份/恢复、单片叶精度自检。

## 内置测试地块

首次打开会写入三块约一亩（约 666.7 m²）的地块，每块包含单篱架、V 形架和棚架方案：

- `南坡向阳园`：坡向 182°，坡度 11°
- `东坡迎暾园`：坡向 92°，坡度 15°
- `平地方正园`：坡度 0°

设置页可随时恢复这些数据。

## 精度与性能验收

### 单片叶公式

自检构造一片水平且关闭遮挡的叶片。公式为：

```text
AM = 1 / (sin(h) + 0.50572 * (h_deg + 6.07995)^-1.6364)
DNI = 1361 * 0.7^(AM^0.678)
I_horizontal_leaf = DNI * sin(h)
I_tilted_leaf = DNI * max(0, abs(n · s))
```

页面和设置页均提供“精度自检”，WGSL 输出的日积分会还原为 W/m² 并与 `DNI × sin(h)` 比较，要求相对误差 `< 1%`。`pnpm test` 中也有 CPU 参考实现的同一断言。

### 一亩地性能

默认完整模型约 10 万片叶、约 1000 个果穗；30 分钟步长约 25 个日照时刻。主要路径为：

1. TypeScript 确定性生成叶片/果穗；
2. 构建 0.4 m 冠层叶面积密度体素；
3. 一次 WebGPU Compute Pass 分发 `leafMain` 和 `fruitMain`；
4. 叶片循环时间步，沿太阳方向在体素场中步进并计算透射率；
5. 回读日累计、时刻序列和果穗结果，在主线程聚合行级统计。

受光推演页会显示包含生成、GPU 提交、等待和回读的总耗时；小于 5000 ms 时以绿色标识。

## 数据与导出

IndexedDB 数据库：`grape-canopy-light-lab`

- `plots`：地块档案和边界
- `schemes`：架式、冠层、天气/推演参数
- `kv`：全局设置
- `runs`：预留推演记录对象仓库

导出：

- 方案行级受光统计 CSV
- 逐叶片直射/散射/总量 CSV
- 逐果穗晒伤评估 CSV
- 多方案对比 CSV
- 当前三维画布 PNG / 正午 / 15 点关键时刻截图
- 全部地块和方案 JSON 备份

## 主要目录

```text
src/
  components/       Vue 通用组件和三维视口封装
  pages/            七个功能页面（snake_case 文件名）
  lib/
    solar.ts        太阳位置、大气质量、DNI/DHI、气温日变化
    canopy.ts       三种架式和程序化冠层生成
    voxel.ts        叶面积密度体素和 CPU 透射率参考
    simulate_cpu.ts CPU 参考求解器
    run_simulation.ts 引擎选择、结果聚合和统计
    validation.ts   <1% 精度验收
    db.ts           IndexedDB 封装和种子
    gpu/shader.ts   手写 WGSL 计算着色器
    gpu/engine.ts   WebGPU 缓冲区、管线和回读
  three/            Three.js 三维渲染器和叶片热图
tests/              Vitest 验收测试
scripts/            本地核心逻辑检查脚本
```

## 说明

三维展示使用 Three.js/WebGL，光照数值计算使用 WebGPU/WGSL Compute。这样可以保证冠层、铁丝、地形和热图渲染兼容性，同时满足“光照计算自己写计算着色器”的要求。WebGPU 不可用时不会伪造 GPU 结果，页面会明确标记为 CPU 参考引擎。
